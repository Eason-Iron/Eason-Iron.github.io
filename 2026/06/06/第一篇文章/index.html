Markdown 零基础文章写作完全指南

Markdown 是一种轻量级标记语言，语法简洁、上手门槛低。它适合日常写作、学习笔记、技术文档和博客文章。下面用几个最常见的例子，演示标题、代码块、图片和表格的正确写法。

代码块

代码块需要使用三个反引号包住，并在第一行写上语言类型。生成网页后，右上角会出现复制按钮和展开/收起按钮。

图片

图片语法是 ![图片备注](图片地址)。如果使用本地图片，建议把图片放到 source/images 或 source/_data/covers 等会被 Hexo 复制到 public 的目录中，然后使用以 / 开头的站内路径。

表格

表格每一行都要使用 | 分隔列，表头下面必须有一行分隔线。不要在表格后面继续写没有 | 的散乱文本，否则 Markdown 可能会把后续内容解析进表格附近，显示就会乱。

语法类型 适用场景 难度
标题语法 搭建文章框架 极低
列表语法 罗列核心要点 极低
表格语法 展示数据对比 低

写作规范

  • 全文建议只使用一个一级标题，正文从二级标题开始分层。
  • 标题、列表、引用、表格等语法符号后面要保留一个空格。
  • 段落之间留空行，能明显提升文章可读性。
  • 图片路径要是真实存在的本地路径或可访问的网络地址。

总结

写 Markdown 时，最容易出问题的地方通常不是主题样式，而是图片路径不存在、表格行缺少分隔符、代码块反引号没有成对闭合。先保证 Markdown 源文件格式正确，再让主题负责美化，页面就会稳定很多。
